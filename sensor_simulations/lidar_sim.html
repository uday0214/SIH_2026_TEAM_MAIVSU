Mathematical Equation & Objective Formulation

1. Multi-Scenario Matrix:
  Test scenario γ = (di, Tj, Wk) ∈ 𝔻5 × 𝕋2 × 𝕎4  (Σ = 40 test cases per sensor)
  • di ∈ {3m, 6m, 9m, 12m, 15m}  • Tj ∈ {Day, Night}  • Wk ∈ {0% (Dry), 25% (Shallow), 50% (Half), 100% (Puddle)}
2. Optimal Look-Down Pitch Angle Theorem:
  θ*(s, di) = argmaxθ Es(di, θ, Tj, Wk) ≈ -arctan(hs / di) + Δθs
  Always centers the sensor aperture / elevation beam cluster onto the pothole cavity floor.
3. Aggregated Detection Effectiveness:
  Ēs = Σi=15 Σj=12 Σk=14 [ wd(di) · wT(Tj) · wW(Wk) · Es(di, θ*, Tj, Wk) ]
4. Weighted Multi-Attribute Utility Function (MAUF) & CER:
  U(s) = wE · Ēs + wC · (1 - Ĉs)       where Ĉs = (Cs - Cmin) / (Cmax - Cmin)
  CERs = (Ēs × 100) / (Cs / 10,000)  [% effectiveness per ₹10,000 cost]
